# Quicknotes

Quicknotes is a small browser-based note-taking app built with HTML, CSS, and vanilla JavaScript. It lets you create notes, organize them by category, search their text or category, and keep them saved in your browser using local storage.

## Features

- Add notes with Personal, Work, or Other categories.
- Show each note's category and creation date and time.
- Delete notes.
- Search notes by text or category.
- Display the total number of notes.
- Save notes in browser local storage so they remain available after a refresh.
- Show validation and storage error messages.
- Responsive styling for smaller screens.

## Run locally

1. Download or clone the project and open its folder.
2. Open `index.html` in a web browser, or launch the folder with a local static web server (for example, the VS Code Live Server extension).
3. Add, search, or delete notes. Notes are stored in the browser's local storage.

## What I learned

- How to structure a page with semantic HTML elements and connect labels to form controls.
- How to create and update page elements with JavaScript using `createElement()` and `textContent`.
- How to handle form input, validate notes, and filter a list as the user searches.
- How to save and load data with `localStorage` and JSON.
- How CSS can make a page responsive and improve visual clarity and keyboard accessibility.
